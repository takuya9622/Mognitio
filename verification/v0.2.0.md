and documentation, including added files. The base revision alone does not

not its build identity.

cold and warm caches and a relocated compiler internally.

## Limits

No required Linux amd64 acceptance case is skipped. Other compiler hosts
and target platforms have not been validated. Generated tests cover bounded
trees, not all possible depths. Power loss, forced termination, uncatchable
resource exhaustion, and simultaneous filesystem changes by other processes
are outside this validation. Release tags identify publication separately from these test results.

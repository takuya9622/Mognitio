# v0.3.0 validation

Validated on 2026-09-14. The [content manifest](SHA256SUMS) identifies the
delivered snapshot; the pull request records the exact tested commit.

## Identity and environment

- Base revision: `e97fa408698828aef8fe0588fd9189b59c2d19fd`.
- Compiler host and execution target: non-root Linux amd64.
- SBCL: `2.6.0.debian`, with bundled SB-POSIX.
- ASDF and UIOP: `3.3.1`.
- Test helper: Python `3.14.4`.
- No additional code-generation configuration or third-party Lisp dependencies.
- Compiler source identity: `7a575b92e1c4e574f5f1faed172fbf508efa3527bc3200cb2a6032119154abde`.

The source identity is SHA-256 of sorted checksum lines for `mognitio.asd`,
`bin/mgn`, `scripts/cli-entry.lisp`, and every `src/*.lisp` file.
Each line contains a lowercase SHA-256 digest, two spaces, a relative path,
and LF. The manifest also covers tests and documentation, excluding itself.
The semantic version alone does not identify compiler contents.

## Commands and results

```sh
sbcl --noinform --script scripts/test.lisp
git diff --check
sha256sum -c verification/SHA256SUMS
```

The complete suite passes with both the ordinary cache and a dedicated empty
cache using the [isolated-cache procedure](README.md#automated-tests).

```text
Tests=48 Assertions=5577 Processes=626 Failures=0
```

The [coverage matrix](../tests/README.md) includes checked signed arithmetic,
local bindings and mutation, lexical scope and initializer reservations,
static checking of both branches, ordered evaluation, typed SSA merges,
instruction bytes, large stack frames, and runtime-error classification.
A separate mathematical evaluator checks 128 reproducible integer programs
against both execution paths. Native syscall fault injection exercises
partial stderr delivery, interruptions, retry exhaustion, and failed writes.
Existing source, CLI, ELF, publication, cache, and boolean regression groups
remain active. The relocated cold/warm-cache fixture includes integers and
mutation.

Source formatting, Markdown relative links and fences, executable launcher
mode, whitespace, and the content manifest were checked. All examples were
run through the host compiler and built into directly executed native files.

## Limits

No required Linux amd64 acceptance case is skipped. Other hosts and targets
have not been validated. Generated inputs cover bounded samples rather than
all source programs. Forced termination, uncatchable resource exhaustion,
and concurrent external filesystem mutation remain outside this validation.
Release publication and tags are separate from these test results.

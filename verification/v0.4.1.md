# v0.4.1 validation

Validated on 2026-09-16. This record covers the parameter syntax correction
in v0.4.1. The original [v0.4.0 validation](v0.4.0.md) remains
historical and describes the earlier compiler.

## Change and compatibility

Function parameters now use `name: type` instead of `type name`.
The colon is required; the old and mixed forms are parse errors.
Function declarations still use `function`, lowercase `int` / `bool`,
and the existing result annotation. Calls remain positional.

The parser preserves each name/type token span and covers the entire
parameter from the name's start to the type's end. Existing fixtures,
generators, examples, and relocation tests use the corrected grammar.
The new annotation group checks whitespace, both types, old/malformed
signatures, diagnostic positions, and output preservation on rejection.

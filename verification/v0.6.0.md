# v0.6.0 validation

Validated on 2026-09-21 for the v0.6.0 source release. Exact tested commits,
commands, results, and integration identities are recorded in the release PRs.
The immutable `v0.6.0` tag identifies the release merge commit on `main`.

## Identity and reproduction

- Supported compiler host and tested target: non-root Linux amd64.
- Toolchain: SBCL 2.6.0.debian, bundled ASDF 3.3.1, Python 3.14.4.
- Full suite requires bundled SB-POSIX and permission to ptrace child processes.
- No new third-party dependencies, assembler, linker, or runtime library.
- [SHA256SUMS](SHA256SUMS) identifies all delivered files, excluding itself.

```sh
sbcl --noinform --script scripts/test.lisp
git diff --check
sha256sum -c verification/SHA256SUMS
```

The final implementation regression gate passed 137 test groups, 15,067
assertions, and 1,368 child processes, with zero failures and no required skips.
Release metadata changes receive the same complete regression gate at their
committed HEAD before integration. The release PR records that result separately.
UTF-8, LF/final newline, whitespace, Markdown links and fences are also checked.

## Behavior and coverage

Version 0.6.0 adds immutable UTF-8 strings, concatenation, content equality
without normalization, and the intrinsic methods `->length()` and
`->slice(start, end)`. Length and slice indices count Unicode scalar values.
Arguments evaluate once from left to right after capturing the receiver value.
Strings can cross function, assignment, block, and loop boundaries.

The [coverage matrix](../tests/README.md) and
[incremental record](v0.6.0-progress.md) cover source rejection, evaluation
order, runtime failures, independently checked Core/root plans, machine frames,
handwritten/generated ABI cross-tests, and host/native results.
All checked-in examples and all four README language examples execute through
host run, native build, and direct native execution.

Host execution uses SBCL GC. Native execution uses precise non-moving
mark-and-sweep collection, shadow root frames, and copied UTF-8 payloads.
Independent bounded-heap tests observe reclamation and reuse; mutants that
omit sweeping or retain every object fail the bounded workload.
Debug root classification rejects interior, freed, forged, and unmapped roots
before reading candidate headers. Normal output contains no debug heap records.

Native artifacts are tested for deterministic cold/warm builds, relocation,
standalone execution, atomic publication, and output faults. Runtime string
bounds, size, and detected allocation failures exit with status 4. Diagnostic
output failures preserve the original failure classification.

## Compatibility and limits

`string` is newly reserved. Rename existing bindings with that name when
migrating from v0.5.0. Method names such as `length` and `slice` remain ordinary
identifiers outside a method call. General user-defined methods, method values,
associated-function syntax, and new I/O facilities are outside this release.
The program entry result remains `bool`.

This is a source release. Building requires SBCL; generated Linux amd64 ELF
executables run without SBCL or libc. Other hosts and targets are unverified.
Finite generated samples and bounded resource tests do not prove all programs.
OS termination, uncatchable host resource exhaustion, and concurrent filesystem
changes are outside the guarantees established by these tests.

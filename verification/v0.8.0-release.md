# v0.8.0 release validation

Date: 2026-09-25

Version 0.8.0 adds explicit generic types and functions, canonical `Result<T, E>`,
prefix `try`, and `panic { ... }`. This is a source release for Linux amd64.
The compiler requires SBCL with bundled ASDF, UIOP and SB-POSIX; generated ELF
executables require neither SBCL nor libc. No prebuilt compiler is distributed.

## Review findings and verification limits

Explicit generic calls resolve to a concrete function reference with a constant
function ID and a verified singleton candidate. Core uses the existing
`:call.value` path; the host backend uses its ordered evaluation and CASE path.
Reusing those paths preserves argument order, call effects, roots and ABI checks
without a separate direct-call emitter. The constant callee has no source side
effects. Template declarations and aliases themselves have no runtime value.
This internal choice does not add runtime type-argument dispatch or source-level
generic function values. No performance improvement is claimed.

The instance verifier separately traverses source and checks cloned nodes,
instance closure and metadata. It shares `substitute-generic-type`,
`derive-function-free-parameters` and `concrete-type-key` with the producer.
Recomputation therefore does not establish algorithm-level independence for
those helpers. Source expectations for int/string/void and nested aggregates,
argument-order/environment/key mutations, descriptor-byte checks and run/native
observations supplement verification. They do not prove the absence of every
common-mode helper defect. A separate reference substitution engine is a future
verification option, not an implemented release feature.

## Compatibility and coverage

Ordinary local `let` / `var` bindings need type annotations. Direct function
signatures, static aliases and pattern bindings retain their distinct rules.
Every generic type argument is explicit; generic templates are not runtime
function values. Rename identifiers that conflict with new keywords `try`
and `panic`. Panic uses an ordinary block, including its earlier control transfer
and failure behavior. Older non-block panic spellings are rejected.

The [implementation record](v0.8.0.md), [source catalog](v0.8.0-cases.json),
[recorded source observations](v0.8.0-results.json), and [test matrix](../tests/README.md)
cover acceptance, lifetime, independent ABI/layout observations, failure
injection, deterministic artifacts and historical regressions. Prior measured
revisions remain historical; release checks do not relabel their observations.

Generic interfaces/methods/implementations, constraints, inference, recovery,
stack traces, defer and new I/O are outside this release. Other hosts and targets
remain unverified. Bounded tests do not establish every possible input or
guarantees for OS termination, host exhaustion or concurrent filesystem changes.

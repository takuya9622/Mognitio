The complete suite passes with the ordinary cache and with a dedicated empty
cache using the [isolated-cache procedure](README.md#automated-tests).

```text
Tests=66 Assertions=8889 Processes=889 Failures=0
```

The [coverage matrix](../tests/README.md#v040-functions-and-returns) maps every
function acceptance case to executable fixtures. Checks include whole-source
name/type/cycle rejection, caller value preservation, every return position,
call spills, symbolic parallel copies, typed internal-boundary failures,
instruction goldens and a handwritten machine caller/callee. Stress fixtures
cover eight mixed arguments, signed boundaries, 24-function chains, 600 live
values and 600 arguments. The separate oracle checks 128 four-function
programs at seed 20260916 and depth 3; existing bool/int oracles remain active.

Cold/warm relocation tests cover forward calls, early returns and runtime
failure. They compare exact bytes, remove the source and copied compiler,
then execute with an empty environment and additional arguments. Actual
native write fault tests cover partial output, interruptions, failed writes
and runtime retry exhaustion. Publication and ELF size checks use function
programs as well as the preceding regression sources.

## Repository review and limits

UTF-8, LF/final newlines, Markdown relative links and fences, whitespace,
launcher executable mode and the content manifest were checked. Public
changes contain no machine setup details or private document links.

No required Linux amd64 acceptance case is skipped. Other hosts and targets
were not validated. Generated cases are bounded samples, not a proof for all
programs. Forced termination, uncatchable resource exhaustion and concurrent
external filesystem changes remain outside this validation. Specification
adoption, internal design status and release publication are distinct states.

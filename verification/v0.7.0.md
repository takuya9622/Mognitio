## Independent internal checks

CheckedProgram verification reconstructs declaration/alias/implementation state
from source order, including predeclared methods within each implementation
block and whole-program interface candidates. Corruption cases cover alias
identity, member slots, packing records, contracts, and dispatch candidates.

Core verification checks nominal slots, payload guards for the same enum SSA
value, guarded-edge dominance, canonical contracts and complete candidate sets.
Root verification independently reconstructs liveness and rejects both a missing
live child and an unnecessarily retained parent. Allocation operands are roots
even when their last use is the allocation itself.

Native ABI v4 uses one hidden receiver word before explicit arguments. A
handwritten callee checks receiver/argument slots and caller-saved register
clobbers. Static descriptor/table bytes are checked against handwritten expected
words, including contract declaration order differing from method source order.
Frame mutations reject a receiver loaded from the table slot. Debug collection
rejects unmapped, interior, free, and forged-static child pointers before reading
their metadata; unknown descriptors/tables and concrete/table mismatches stop
with internal exit 3 and empty streams.

## Reclamation measurements

The graph fixture allocates a text-containing struct inside an enum and an
interface box, with a shared leaf. It also retains an extracted child while its
original parent becomes unreachable. The independent Python observer reads
physical arena blocks and static metadata from the artifact, follows the box's
five-object graph, and confirms that the discarded parent is absent.

| Mode | Allocations | Requested physical bytes | Collections | Reclaimed blocks | Mapped bytes | Peak live | Peak roots | Max mark passes |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Normal trigger | 8,013 | 354,096 | 96 | 7,981 | 4,096 | 368 | 48 | 6 |
| Every allocation | 8,013 | 352,560 | 8,014 | 8,005 | 4,096 | 432 | 80 | 6 |

Physical byte totals include unsplit remainder space and therefore can differ
between collection schedules. Both modes observe one complete allocated,
reclaimed, and reallocated block lifecycle at the same address. This is a lower
bound on reuse, not a total reuse count. No-sweep and all-mark mutants exhaust
the cap; disabled tracing loses the required result or fails. An extra-parent
retention mutant still computes true but fails the independent heap observer.

The separate forty-level shared graph stays within 4,096 mapped bytes, reaches
2,040 peak live bytes, and requires at most 43 fixed-point passes over 443
collections. A representative instrumented process took about 0.0035 seconds;
this is a bounded fixture measurement, not a performance guarantee.

Host weak-reference observation tracks 20,002 aggregate/box allocations and
confirms all 20,002 become collectable after execution. Native and host evidence
are independent; RSS or collection count alone is not a pass criterion.

# v0.8.1 release validation

Date: 2026-09-26

Version 0.8.1 requires every local binding to declare its type. Function types
are ordinary types, so an immutable local can hold a matching function value.
Generic signatures are `let`-only binding annotations, compared by
alpha-equivalence, and are not runtime types. Generic struct fields and enum
payloads reject function types. This is a source release for Linux amd64.
The compiler requires SBCL with bundled ASDF, UIOP and SB-POSIX; generated ELF
executables require neither SBCL nor libc. No prebuilt compiler is distributed.

## Binding rule

Ordinary `let` and `var` bindings declare a type. The compiler computes the
initializer's normal type and checks the existing adaptation rules. Function,
branch, loop, constructor and call initializers use that same rule. A missing
annotation, a `_` annotation, and local type inference are rejected.

```mgn
let op: function(int): int =
    function(value: int): int { value + 1 };
```

A generic template and a static alias to one require a generic signature on
`let`. `function<A>(A): A` and `function<T>(T): T` are the same signature.
`var` cannot bind a generic template or a function value. A generic template
cannot flow into a runtime value position. Method bindings and pattern bindings
keep their existing unannotated forms.

Function types are rejected as parameters, returns, struct fields and enum
payloads, including fields and payloads of generic structs and enums.

## Compatibility and coverage

v0.8.0 behavior for generics, canonical `Result`, prefix `try`, and block
`panic` remains. The historical [v0.8.0 catalog](v0.8.0-cases.json) again
matches [v0.8.0-results.json](v0.8.0-results.json). Prior measured revisions
remain historical; this release does not relabel them.

Generic interfaces, methods, implementations, constraints, inference, recovery,
stack traces, defer and new I/O remain outside this release. Other hosts and
targets remain unverified. Bounded tests do not establish every possible input
or guarantees for OS termination, host exhaustion or concurrent filesystem
changes.

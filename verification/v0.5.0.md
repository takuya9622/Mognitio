## ABI review follow-up

The original handwritten-only ABI fixture did not connect either side to
production lowering. Two cross-tests now retain one production-generated
side and substitute a handwritten unit only on the other side. They check
mixed void/int/bool arguments, a zero void result, stack restoration and
values live across a call that clobbers all allocation registers in a loop.
Three injected errors (argument-slot compaction on either generated side,
and a nonzero generated void result) produce the expected failures.

The focused gate passed: 2 tests, 28 assertions, 5 processes, 0 failures.
The exact follow-up HEAD and full regression result are recorded in its PR.
The initial implementation gates above remain historical. Compiler source
and emitted example artifact identities are unchanged by these test and
documentation changes.

## Boundaries

Function IDs and structural types replace named declarations; ordinary
source cannot supply arbitrary call targets. Void has its own host value
and a zero native word. Loop CFGs use fixed-point dominance and liveness;
separate metadata, dominance and instruction-level live-demand checks
reject deliberately corrupted inputs. Whole-interval spills retain
values across calls and backedges.

Compatibility migrations are documented in the coverage matrix; historical
records remain unchanged. The required Linux amd64 cases have no skips.
Other hosts and targets are unverified. Generated bounds and one-second
nontermination observations are test limits, not language limits or a
proof for all possible programs.
